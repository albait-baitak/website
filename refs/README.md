# مكتبة قواعد الفحص الفني ٢ (مسودة بانتظار الاعتماد)

- rules_v2.json: 101 قاعدة بنصوص بنودها الحرفية وأرقامها كما تُطبع في المراجع. لم تُربط بالمحرك بعد.
- lib_*.json: استخراج المراجع الرسمية (الاشتراطات السكنية، دليل عمارة واحات الأحساء، دليل المواقف).
- audit.json: مراجعة مستقلة لكل بند على النص الأصلي.

نصوص المراجع الكاملة محفوظة في جدول ref_docs في Supabase (للمشرف فقط).
